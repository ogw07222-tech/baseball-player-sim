## Scope
This port moves the validated H3.1 pitch/contact/batted-ball/defense model and
H3.2.1 baserunning formulas into production `src/` without importing
`tools.balance_lab`.

The legacy public simulation entry points remain available:
- `simulate_plate_appearance(...) -> str`
- `simulate_player_game(...)`

A new detailed internal API is added:
- `simulate_plate_appearance_outcome(...)`
- `src.hitting.baserunning.GameState`

## Production architecture
- `src/hitting/parameters.py`: frozen validated constants.
- `src/hitting/model.py`: pitch, swing, contact, quality, batted-ball, HR and
  hit-candidate resolution.
- `src/hitting/defense.py`: difficulty-tier catch and damage suppression.
- `src/hitting/baserunning.py`: H3.2.1 steal, 1B->3B, 2B->Home and DP formulas.
- `src/simulation.py`: Player/trait/form adapters and compatibility game flow.
- `src/records.py`: backward-compatible optional SB/CS/baserunning diagnostics.

## Formula changes
None to the validated neutral-profile formulas.

Production-only wrappers:
1. Existing trait/form/fatigue effects are applied as per-pitch Contact/Power
   input adjustments. They are neutral for the Balance-Lab baseline.
2. The current career engine does not simulate every teammate PA. The new
   `GameState` API accepts real inning/base state when provided; existing career
   callers use a deterministic abstract-state adapter. Between-PA advancement
   uses the validated H3.2.1 opportunity-rate constants until a full-team inning
   engine exists.
3. The legacy `steal_sense` trait is intentionally not layered on top of the
   frozen H3.2.1 steal equations. Reintroducing a trait modifier requires a
   Balance-Lab validation pass.

## Save compatibility
`BattingLine` adds optional fields with zero defaults:
`ROE`, `GDP`, `SB_attempts`, `DP_avoided`, `XBT`, `XBT_attempts`,
`first_to_third`, `second_to_home`.

`BattingLine.from_dict()` defaults all new keys to zero, so older save payloads
remain loadable. Existing save serialization includes the new fields
automatically on the next save.

## Remaining risks
- The project still lacks a full-team inning simulator. Real `GameState` can be
  supplied now, but the existing career path uses an abstract compatibility
  state for omitted teammate plate appearances.
- HBP generation is not part of the validated H3.1 math and therefore remains
  schema-compatible but is not generated by the new neutral H3 path.
- `steal_sense` is not applied until separately revalidated.
- Existing real-player ratings are not refit in this port.
