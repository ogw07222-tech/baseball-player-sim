# League System

## 목적

선수의 커리어가 한 리그에 고정되지 않고 여러 야구 환경으로 확장될 수 있게 한다.

## 기본 원칙

리그 수준 차이를 선수 스탯 자체를 강제로 변환하는 방식으로 처리하지 않는다.

예:
- KBO에서 컨택 130인 선수가 MLB로 이동해도 컨택 130 유지
- 대신 MLB 투수들의 평균 구위/제구/구종 수준이 더 높아 실제 성적이 달라짐

즉, 리그 난이도는 **상대 선수 풀의 수준과 환경**으로 표현한다.

## 초기 고려 리그

- KBO 1군
- KBO 2군
- NPB
- MLB
- MiLB

향후 필요하면 기타 리그 추가 가능.

## 리그별 차이 후보

- 선수 평균 능력 수준
- 시즌 경기 수
- 엔트리/로스터 규칙
- 외국인 선수 규정
- 포스트시즌 방식
- FA/포스팅 규칙
- 구장 환경
- 이동/피로
- 일정 밀도
- 공인구/리그 run environment

## 선수 이동

후보 경로:
- 신인 드래프트 → KBO 입단
- 2군 ↔ 1군
- KBO FA 이적
- 트레이드
- 포스팅을 통한 MLB 진출
- 해외 FA
- MLB ↔ MiLB 승강격
- NPB 진출
- 해외에서 KBO 복귀

## 수준 평가

리그에 하나의 단순 난이도 배율을 곱하는 방식은 가능하면 피한다.

실제 경기 엔진에서는 상대 투수/타자/수비수의 개별 능력치를 사용해 결과를 만들고, 리그 전체 수준은 그 선수 풀의 분포에서 자연스럽게 나타나게 한다.

## 미확정

- 각 리그의 평균 능력치 분포
- 리그 간 정확한 수준 차이
- 실제 규정 반영 범위
- 실존 팀/선수 데이터 사용 여부
- 시즌 시작 연도
